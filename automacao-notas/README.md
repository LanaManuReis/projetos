# 📚 Automação de Notas

## Sobre o projeto

Sistema desenvolvido em Python para automatizar o cálculo de médias escolares, identificar alunos aprovados ou reprovados e gerar relatórios de desempenho.

## Funcionalidades

* Receber o nome e as notas dos alunos.
* Validar notas entre 0 e 10.
* Calcular a média de duas notas.
* Identificar a situação escolar, considerando média mínima 6,0.
* Gerar um relatório de desempenho para cada aluno.

## Organização do código

O programa utiliza a estrutura Entrada, Processamento e Saída (EPS), com funções separadas para cada responsabilidade.

## Tecnologia utilizada

* Python 3

## Como executar

No terminal, dentro da pasta do projeto, execute:

```bash
python app.py
```
