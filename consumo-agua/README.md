# 💧 Sistema de Consumo de Água

Este projeto foi desenvolvido em Python para classificar o perfil de consumo de água de diferentes tipos de imóveis e emitir alertas educativos aos moradores.

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 💻 Visual Studio Code
- 🐙 GitHub

## 🎯 Objetivo

O sistema recebe o tipo de imóvel e o consumo mensal de água em metros cúbicos (m³). A partir dessas informações, o programa classifica o consumo de acordo com regras definidas e apresenta uma mensagem educativa ao usuário.
