O projeto a seguir calcula o consumo mensal e o custo estimado de um aparelho com base na potência e no tempo de uso.

##🐍 Linguagem utilizada
A linguagem utilizada para criar o projeto foi Python.

### 🧮 Fórmula Utilizada

A fórmula utilizada para calcular o consumo mensal e o custo estimado foi:

`consumoMensal = potencia * horasDia * 30 / 1000`

`custoMensal = consumoMensal * 0.75`

#### ▶️ Instruções para executar o programa.
 1. Abra o terminal na pasta do projeto.
 2. Execute o arquivo `app.py` utilizando o comando `python app.py`.
 3. Forneça as informações que serão solicitadas, como o nome do aparelho, a potência e o tempo de uso.
 4. Após isso, esses dados serão processados e você receberá o consumo mensal e o custo estimado do seu aparelho.
